# VetHub

## Sobre o Projeto
Sistema de gerenciamento para clínicas veterinárias.

## Status
Em desenvolvimento.

## Equipe de Desenvolvimento
Arthur Fontoura

## Tecnologias Utilizadas
* Java 17.0.6
* MySQL
  
## Funcionalidades
* Cadastro de usuários, animais, clientes
* Agendamento de consultas e outros procedimentos
* Prontuário digital com histórico completo dos animais
* Buscas por cada tipo de informação
* Controle de permissões (Gerente, Atendente, Veterinário)
